## Superficies

- `wrangler.jsonc`: `main = src/worker/index.js`, `assets = ./public`, binding `DB` (D1).
- `migrations/0001_init.sql`: **el esquema completo del spec §3.3**, con las dos
  correcciones exigidas por ADR-003 (`applications.status_previo`, y `idx_docs_actual`
  como índice parcial **UNIQUE**). El Ciclo 1 **solo usa** `job_offers`, `applications` y
  `login_attempts`; las otras tablas quedan creadas y **vacías**.
- `package.json` con `dev`, `build` y `test`. Gestor: **npm**.
- SPA React + Vite que compila a `public/`. Cuatro pantallas navegables y una barra
  lateral. **Los tokens visuales son los de acá abajo, literales** — la referencia visual
  son las capturas `docs/mockup/capturas/*.png`.

  ```css
  :root{
    --bg:#f7f7f8; --panel:#fff; --line:#e4e4e7; --ink:#18181b; --dim:#71717a;
    --accent:#4f46e5; --accent-soft:#eef2ff; --warn:#b45309; --warn-soft:#fef3c7;
    --ok:#15803d; --ok-soft:#dcfce7; --bad:#b91c1c; --bad-soft:#fee2e2;
    --sidebar:240px; --gap:24px; --radius:10px;
  }
  ```

  **No abras ni busques el HTML del mockup** (`docs/mockup/public/index.html`): es
  material de referencia del diseño, no una fuente que importes. Ningún archivo de `src/`
  ni de `tests/` puede leerlo.
- `GET /` sirve la SPA; las rutas de la API viven bajo `/api`.
- `tests/fixtures/`: **una entrada HTML por pantalla** (`login.html`, `pipeline.html`,
  `nueva-oferta.html`, `detalle-oferta.html`), cada una **importando el componente real**
  con datos fijos. Son **entradas extra de Vite**: se construyen con la SPA.
  `C-01`, `C-07`, `C-14` y `C-18` se verifican ahí con `tests/helpers/browser.mjs`, porque
  una SPA **no tiene DOM hasta que corre el JS**: el elemento no se puede encontrar
  leyendo el HTML.

## ADR aplicables

- **ADR-001** (un Worker con `main` + `assets`, no Pages).
- **ADR-002** (npm, sin monorepo).
- **ADR-003** (una sola migración con el esquema completo y sus dos correcciones).
